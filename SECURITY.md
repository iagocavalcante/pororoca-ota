# Security

Do not open a public issue for a suspected vulnerability. Email `hello@pororoca.dev` with the affected component, reproduction steps, and impact. Do not include production tokens or private signing keys.

We will acknowledge a report as soon as practical, investigate it, and coordinate disclosure and remediation with the reporter.

## Supported versions

Pororoca is early access. Security fixes are made on the latest revision of `main`; pin a reviewed commit in production and upgrade deliberately.
